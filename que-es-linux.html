Software libre: el código está abierto

En Linux puedes leer, modificar y compartir el código, y casi todas las distribuciones son gratis. En Windows el código es cerrado y lo controla Microsoft.

Los archivos viven en un solo árbol

Windows reparte el disco en unidades con letra. Linux parte de una única raíz, /, y todo cuelga de ella.

Windows
C:\├ Usuarios\│ └ ana\D:\
Linux
/├ home/│ └ ana/├ etc/└ usr/
6 de 7 · Entiende

Linux distingue mayúsculas y minúsculas

Esto importa en la terminal: un nombre escrito con otra mayúscula es otro archivo.

Windows
Foto.png=foto.png

Es el mismo nombre.

Linux
Foto.png≠foto.png

Son dos archivos distintos.
